My Explanation for Game Mechanics, Systems & Loops

Game Mechanics

Game mechanics are the most important part of any game. They are the rules that define what players can do. Some completely warp how the game is played, while others expand upon that experience.


There are many ways to define/categorize game mechanics. One useful framework, made by game designer Charmie Kim, separates a game's mechanics into four layers:

  • Core mechanic(s) are systems which make up the game's primary gameplay loop.
  • Secondary mechanics aren't essential for the core gameplay loop, but add depth to it.
  • Progression mechanics determine how the player's/game's state changes over time.
  • The narrative gives context and meaning to the player's actions and the game's mechanics within its world.

As an example, here is how I would fit a few mechanics from League of Legends into this framework:

LoL's core mechanics

Moving, attacking, using abilities, and taking/dealing damage are examples of interactions that repeatedly form the game's core combat loop.

Some of LoL's secondary mechanics

Recalling, warding, pinging, and taking objectives support the core gameplay while giving it strategic depth.

LoL's progression mechanics

Items, leveling up, role quests, and map pressure create a layer of progression in a way that's meaningful for the rest of the game.

LoL's narrative layer

League's worldbuilding and characters improve the game feel in different ways.


Creating fun mechanics takes a lot of creativity and refinement. It gets very difficult sometimes, but that makes the process also that much more enjoyable for me.

When designing these game mechanics, I think it's important to design them while considering how they fit within the larger systems of the game. No mechanic should be designed in isolation because they work together in either Game Systems or Game Loops.

Game Systems

A game system is comprised of multiple game mechanics. Some examples of game systems are movement, combat, shops, crafting, quests, dialogue, an enemy, multiplayer, etc.


Game Loops

I believe that every game has at least one game loop: a repeating sequence of actions that keeps the player engaged which drives the entire game's experience.

  • In Tetris,
    • The player receives a tetromino
    • The tetromino is placed
    • The game evaluates the resulting board
    • Repeat
  • In VALORANT,
    • Preparation time
    • The barrier drops
    • A combat system happens
    • The round ends when a wincondition is reached
    • Repeat
  • In Life is Strange,
    • The player is presented with new narrative
    • The player may explore the environment and interact with characters or objects
    • The player makes decisions that influence the experience
    • The story progresses
    • Repeat
