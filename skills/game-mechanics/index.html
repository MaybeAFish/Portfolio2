Game Mechanics

Game mechanics are the most important part of any game. They are the rules and systems that define what players can do. Some completely warp how the game is played, while others expand upon that experience.


There are many ways to define/categorize game mechanics. One useful framework, made by game designer Charmie Kim, separates a game's mechanics into four layers:

  • Core mechanic(s) are systems that make up the game's primary gameplay loop.
  • Secondary mechanics support or add depth to the core gameplay, but are generally less centralized.
  • Progression is about how the player's/game state changes over time.
  • The narrative gives context and meaning to the player's actions and the game's mechanics within its world.

LoL's core mechanics

Moving, attacking, using abilities, and taking/dealing damage are examples of interactions that repeatedly form the game's core combat loop.

Some of LoL's secondary mechanics

Recalling, warding, pinging, and taking objectives support the core gameplay while adding strategic depth around it.

LoL's progression mechanics

Items, leveling up, role quests, and map pressure create a clear sense of progression in a way that feels meaningful for the rest of the game.

LoL's narrative layer

League's worldbuilding and characters enhance the game feel in different ways.


The core mechanics diagram works great. However, I've recognized that game mechanics are still an inconsistently defined concept; There is no universally accepted framework for categorizing them.

I would personally argue that it'd be more useful to categorize game mechanics based on their specific purpose (systemic, narrative, reward, feedback, meta (inventory), etc) instead of forcing them into a fixed hierarchy. Despite that, I still support Charmie Kim's diagram as it's currently the most practical design tool for game mechanics I've found.
