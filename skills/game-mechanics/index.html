Game Mechanics

Game mechanics are the most important part of any game. They are the rules and systems that define what players can do. Some completely warp how the game is played, while others expand upon that experience.


There are many ways to define/categorize game mechanics. One useful framework, made by game designer Charmie Kim, separates a game's mechanics into four layers:

  • Core mechanic(s) are systems which make up the game's primary gameplay loop.
  • Secondary mechanics aren't essential for the core gameplay loop, but add depth to it.
  • Progression mechanics determine how the player's/game's state changes over time.
  • The narrative gives context and meaning to the player's actions and the game's mechanics within its world.

As an example, here is how I would fit a few mechanics from League of Legends into this framework:

LoL's core mechanics

Moving, attacking, using abilities, and taking/dealing damage are examples of interactions that repeatedly form the game's core combat loop.

Some of LoL's secondary mechanics

Recalling, warding, pinging, and taking objectives support the core gameplay while giving it strategic depth.

LoL's progression mechanics

Items, leveling up, role quests, and map pressure create a layer of progression in a way that's meaningful for the rest of the game.

LoL's narrative layer

League's worldbuilding and characters improve the game feel in different ways.


The core mechanics diagram works great. However, I've recognized that game mechanics are still an inconsistently defined concept; There is no universally accepted framework for categorizing them.

I would personally argue that it'd be more useful to categorize game mechanics based on their specific purpose (systemic, traversing, narrative, reward, feedback, meta (inventory), etc) instead of forcing them into a fixed hierarchy. Despite that, I still support Charmie Kim's diagram as it's currently the most practical design tool for game mechanics I've found.

Game Loops

I believe every game has at least one game loop: a repeating sequence of actions that keeps the player engaged and drives the entire game's experience.

  • In Tetris,
    • The player receives a tetromino
    • The player positions and places the tetromino
    • The game evaluates the resulting board
    • Repeat
  • In VALORANT,
    • The round begins
    • Players make decisions and interact with the opposing team
    • Players fight for an objective
    • The round ends when a wincondition is reached
    • Repeat
  • In Life is Strange,
    • The player is presented with a new part of the narrative
    • The player may explore the environment and interact with characters or objects
    • The player makes decisions that influence the experience
    • The story progresses
    • Repeat

Here are some game loops I've designed:


Turn-based match-3 game

  • The player is prompted with a Quick Time Event (QTE) to earn moves
  • The player uses those moves in a match-3 field to accumulate damage
  • The player decides which enemy to attack to use the damage on
  • The enemy(s) strike back
  • Repeat

Doomed's Horde Mode

  • The round starts
  • After a short duration, enemies start spawning into the arena
  • The player must kill all the enemies
  • The player occasionally gains a new weapon
  • Repeat
