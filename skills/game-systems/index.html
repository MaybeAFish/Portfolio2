Game Systems

A game system is comprised of multiple game mechanics.

Examples of game systems are movement, combat, shops, crafting, quests, dialogue, enemy AI, loot, multiplayer, etc etc etc.

I have designed various game systems:


Karaoke Play of the Game

I designed a system that identifies the most memorable 15 seconds of a player's performance. Different moments throughout the song were given different weights based on how entertaining or significant they were, with the highest-scoring segment being replayed at the end of the session.

Gameplay under NDA


Procedural dungeon generation

I designed a system for random dungeon generation. I used delauney triangulation to decide on potential room positions. Spawned those rooms randomely based on a seed. Pushed them together as close as possible in a grid. And used the a* algorithm to force hallways between them.


Controls system

I designed the controls system for the ice hiker. A system which rotates the camera when the mouse is moved, lets the camera collide with terrain using raycasts, and lets the player move in the direction the camera is looking at.

I designed it this way, because I wanted the player to look at the face of the character without the camera being difficult to control.


Animation system

I also designed an animation system for the Ice Hiker, which allows for any mechanic that wants to play an animation to play depending on how much weight that animation has. If the animation a mechanic wants to play has more weight than the currently playing one, it will hold priority.


Minigame system

I designed a minigame system which worked differently compared to the default exercise system.
