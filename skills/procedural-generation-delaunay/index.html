Making a Replayable Procedural Dungeon

I created a random dungeon generation system. I used delauney triangulation to decide on potential room positions. Spawned those rooms randomely based on a seed. Pushed them together as close as possible in a grid. And used the a* algorithm to force hallways between them.

All of this was done in MonoGame, which at the time was primarily used to create 2D games.
