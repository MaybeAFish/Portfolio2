Horde Mode

Near the end of the project, we decided to add a Horde Mode to Doomed. Another team member had originally taken on the task, but ran into enough problems that we were ok with leaving it unfinished.

With very little time left before the showcase, I tried working on it anyways, and I managed to make all of the functionality for the game mode in roughly two days.


The game loop

The goal is simply: survive increasingly difficult rounds of enemies.

  • The round starts
  • After a short duration, enemies start spawning into the arena
  • The player must kill all enemies as prompted by the UI
  • The player occasionally gains a new weapon
  • Repeat until death

I had included quest UI in the top-left that keeps track of the remaining enemies. This gives the player a visible objective without having to constantly search the arena to figure out whether the round is finished.


Reflection/Leftover ideas

If I had more time for the mode, I would've created the following:

  • A system with deadly terrain, (like lava, or Fortnite's storm), that would force the player to traverse the horde mode map. Currently, the player is only really told to stand around the same area.
  • Weapon ability drops across different rounds. Currently, only the weapons themselves drop while the game already has an entire ability system in place.
  • A better system for regaining ammo, like landing headshots for the pistol maybe, or enforcing ability usage (enemies drop more ammo while under a status effect).
  • Design up to 100 rounds. I had only done 10, with the last one being basically impossible so that players during the showcase wouldn't be able to see that I had only designed 10...
  • Somehow allow the player to use map objects creatively to kill the enemies.
  • A better, more appropiate spawning area for the golem boss, as he felt out of place outside of his usual arena.
  • A shop. Maybe, instead of enemies dropping ammo, and rounds dropping weapons, the player could use coins to purchase weapons and ammo and attachments and abilities.
