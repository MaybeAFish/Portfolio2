Horde Mode

Near the end of the project, we decided to add a Horde Mode to Doomed. Another team member had originally taken on the task, but ran into enough problems that we were ok with leaving it unfinished.

With very little time left before the showcase, I tried working on it anyways, and I managed to make all of the functionality for the game mode in roughly two days.


The game loop

The goal is to survive increasingly difficult rounds of enemies.

  • The round starts
  • After a short duration, enemies start spawning into the arena
  • The player must kill all the enemies
  • The player occasionally gains a new weapon
  • Repeat

My leftover ideas

If I had more time for the mode, I would've created the following:

  • A system with deadly terrain, (like lava, or Fortnite's storm), that would force the player to traverse the horde mode map. Currently, the player is only really told to stand around the same area.
  • Ability drops across rounds. Currently, some rounds will drop weapons, while the game already has an entire ability system in place.
  • A better system for regaining ammo, like landing headshots with the pistol maybe, or enforcing ability usage (enemies drop more ammo while under a status effect).
  • Design up to 100 rounds. I had only done 10, with the last one being basically impossible so that our players during the final showcase wouldn't be able to see that I had only designed 10...
  • Somehow allow the player to use map objects creatively to kill the enemies.
  • A better, more appropiate spawning area for the golem boss, as he felt out of place outside of his usual arena.
  • A shop. Enemies could drop coins instead of ammo. The player could use those coins to purchase weapons, specific ammo, attachments, abilities, traps, or more. This would allow for more player choice, and it would also create a small break inbetween the rounds with constant action.
