Multiplayer Stability

I handled multiplayer edge cases that made the game resilient when players performed actions such as disconnecting or rejoining mid-session.

Whenever I'd discover a new edge-case scenario, I'd propose a solution to the Creative Director before we'd discuss for the desired behaviour.


Edge cases I've handled

  • Marathon player disconnects:
    • Pauses the game if you're playing alone.
    • Pauses your playingfield if one other person is playing with you, without disrupting the second player's game. The disconnectee's playingfield will show a 20-second timeout to reconnect before KO'ing.
  • Marathon player reconnects:
    • Resumes the game if you were playing alone.
    • Resumes your playingfield if someone else was playing with you.
  • Battle player disconnects:
    • Pauses the entire game for everyone, and shows a 10s timer on the disconnectee's playingfield. If the 10s timer passes, the game resumes and the disconnectee's playingfield shows "DISCONNECTED".
    • If multiple people disconnect, the game ensures all affected players' timers have passed before resuming the game.
  • Battle player reconnects:
    • If the player survives long enough to reconnect, the player can continue playing.
  • Joining as a new player when the host has the leaderboard screen open:
    • The controller updates their global and friends' rankings accordingly based on which state the host has selected.
  • Joining as a new player while an existing game is in progress:
    • The controller will tell the player to wait their turn.
  • Joining as a new player while the game is in it's resultscreen:
    • The controller will tell the player to wait their turn.
    • Specifically in the marathon mode (where only 1-2 players are allowed because of the big playingfields), the host won't be allowed to restart the game if the new player exceeds the 2 player limit.

Handling these situations gracefully matters a lot for players. If the behaviour ends up being stupid or buggy, if it wasn't clear who the disconnectee is, or if the disconnectee would gain an unfair advantage, players would get frustrated.
