Tetris Airconsole

Tetris Airconsole is an official Tetris title built for the Airconsole platform for an in-car multiplayer experience, where players connect through their phones and interact with the game on a shared screen.

Airconsole works together with external game companies, such as Wanted Game Studio, to develop games like these. I was lucky enough to intern for Wanted while they were tasked with developing Tetris Airconsole.


During the project, I built and iterated on game-state recovery flows, multiplayer feedback systems, controller UX, and visual polish for a strong in-car competitive experience.

This project has taught me the following Cocos Engine Typescript Localization. Making sure any text in a game translates properly. Working very closely with a Creative Director Working very closely with a Lead Developer Working with Slack Working with Jira / Working with a kanban board Working with Figma Working with the Airconsole API Working with a statistics API from GameAnalytics 9-slicing game art Various easing functions
