Tetris Airconsole

Tetris Airconsole is an official Tetris title built for the Airconsole platform for an in-car multiplayer experience, where players connect through their phones and interact with the game on a shared screen.

Airconsole works together with external game companies, such as Wanted Game Studio, to develop games like these. I was lucky enough to intern for Wanted while they were tasked with developing Tetris Airconsole.



My contributions for this project:

  • Game-state recovery flows
  • Multiplayer feedback
  • Implementing UI, UX, interactions & animations
  • Analytics

I've learned a lot during this project:

  • Cocos Engine and TypeScript
  • The AirConsole API
  • GameAnalytics API
  • Localization and making sure in-game text can be properly translated
  • 9-slicing game art
  • Various easing functions for smooth UI and gameplay transitions
  • Working with Figma to implement UI designs and compare UX flows
  • Working with Jira (kanban board-based workflow)
  • Working with Slack for daily team communication
  • Working closely with a Creative Director
  • Working closely with a Lead Developer
