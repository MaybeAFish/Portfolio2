Tetris Airconsole

Tetris Airconsole is an official Tetris title built for an in-car multiplayer experience, where players connect through their phones and interact with the game on a shared screen. The project was created by Wanted 5 Games, later rebranded as Wanted Game Studio, and I was lucky enough to intern during its development.

Studio Wanted 5 Games
Role Gameplay & UI Intern
Platform AirConsole / Car Play

What I added

I implemented, tested, and iterated on a wide range of multiplayer gameplay and UX systems, helping the team support disconnect scenarios, controller flow, and responsive in-game feedback.

  • Worked closely with the creative director to test and solve disconnect and reconnect edge cases.
  • Handled disconnects in singleplayer, including auto-pausing and lobby timeouts when other players were waiting.
  • Supported player rejoin flows mid-game, including wait states for late joiners and correct UI states on controller devices.
  • Implemented timeout-based disconnect handling and competitive-mode pause logic with synchronized player feedback.
  • Designed the flow where a disconnected player’s board shows a “Disconnected” state while still allowing them to continue if they reconnect before dying.
  • Managed reconnection timing rules, including the 3-second resume delay and waiting for multiple disconnects to recover.
  • Built the phone-side hold preview, showing the current Tetris piece before it is used.
  • Implemented UI and UX transitions across screen and controller devices, including subtle motion, masking, and mode-switch feedback.
  • Created the double and triple clear feedback popups for 2-line and 3-line clears.
  • Added multiple controller UX improvements, including the carousel flow and horizontal-mode support across every interface state.
  • Researched and implemented haptic feedback on both Android and iPhone devices.
  • Built a small prototype to test different buzzer patterns, which the creative director used to communicate the intended feedback language.
  • Added the final haptic feedback implementation for gameplay actions and interactions.
  • Implemented the math and animation for the lightning shader used when sending garbage to opponents.
  • Handled the calculation, keyframing, and timing for the projectile’s start and end states, including its trajectory.
  • Proposed and implemented the level-up animation in Marathon mode, adding feedback where there had previously been none.

Screen & controller work

  • Screen: mode button masking, gamemode switch animation, clear feedback popups, and lobby/game-state transitions.
  • Phone: controller carousel, responsive horizontal layout support, haptics, and feedback-driven interaction polish.
