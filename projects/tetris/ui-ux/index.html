UI, UX & Interaction

UX

  • Controller:
    • Implemented a landscape layout for every single interface to support both phone orientations.
    • Implemented a preview of the currently held tetromino directly on the player's phone.
    • Built a carousel for navigating the gamemodes.
    • Proposed and added non-hosts being able to view their own best score/time in the leaderboard screen.
    • Implemented feedback when you have no leaderboard entry.
  • Screen:
    • Implemented feedback when you have too many or too few players for a gamemode.

UI Feedback

  • Controller:
    • Made sure every button reacts the exact same way when pressed.
    • Created the settings menu transition when opening/closing it.
    • Implemented various feedback animations when opening the leaderboard.
    • Implemented consistent rounding to .00 instead of .000 for time-based results.
  • Screen:
    • Created the background UI mask gliding in and out when switching between lobby/leaderboard/match.
    • Created the animation that plays when switching between game modes.



Haptic Feedback

  • Researched haptic feedback solutions for both Android and iOS devices.
  • Created a prototype on my own initiative that allowed the Creative Director to test and compare different haptic feedback patterns.
  • The Creative Director used the prototype to help establish which haptic feedback should be used for which player actions, I then implemented those actions, including a setting to turn it off.
