Lightning Animation

I implemented the mathematical logic behind a lightning effect that visually connects the line a player clears to the destination of the garbage they send. The effect was designed to make the connection between clearing lines and sending garbage immediately readable to the player.

I was provided with the initial line shader and a concept GIF, and was responsible for turning these references into an actual implementation within the game.


How I Did This

  • The first thing I did was defining the start and endpoints of the animation whenever garbage was sent, with the effect originating from the relevant cleared line and ending at each opponents' playingfields' garbage column's top most empty cell + amount of cells being sent.
  • Then, I calculated a parabolic trajectory of the line between those two points. I made sure the parabole's maximum was calculated lower at larger distances, otherwise the animation would sometimes reach out of bounds.
  • Afterwards I created an instance of the line shader for each garbage being sent, which follows a number of points on this parabole.
  • I then proceeded to animate these lines using Cocos' tween function while making it appear as if the electricity is travelling towards its destination to make it feel directional. This was done using three sets of keyframes.
    • The first set of keyframes makes the line grow from it's starting point.
    • The second set of keyframes holds the line while it touches both ends of the trajectory.
    • The last set of keyframes completely retract the line before despawning.
  • I also created a secondary animation which animates the line thicknesses on various parts of the line, to even further sell the illusion that it's travelling towards the destination.
  • At this point, the line itself is done. All that is left are the particles.
    • A start particle with a decaying size.
    • An end particle that shows an impact effect with a random rotation, with a bunch of small electricity like spark particles flying off in random directions using a particlesystem.
  • Finally, added a 9-sliced bar at the destination, positioned over the garbage indicator next to the opponent's playfield when the impact lands. This bar was stretched to fill all the garbage cells that were being sent
